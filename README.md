# MyTaskDock website

Public product website for MyTaskDock, an early Windows desktop app for personal work tracking.

This repository contains the website only. The desktop application's source is maintained separately in a private repository.

## Static site

- `index.html`: English product page.
- `ko/index.html`: Korean product page.
- `assets/site.css`: responsive styling.
- `assets/site.js`: progressively enhanced navigation, product tabs, image viewer, and email-address copying.
- `assets/images/`: product images made from real WPF views with fictional example data.
- `CNAME`: `mytaskdock.xyz`.

No build step, package installation, external fonts, or third-party JavaScript is required. Keep all files at the publishing root. The offline preview HTML files supplied separately are not deployment files.

## Product snapshot

The copy describes source version 0.4.8, reviewed October 7, 2026. The current desktop interface is Korean. English task text in images is example content, not an English-localization claim.

Claude features are proposals for evaluation, not implemented functionality or a committed release schedule. Other suggested directions are also labeled as unimplemented proposals. Optional future sections are marked with HTML comments in both language pages.

Contact links open an email client. There is no public-download handler, mailing-list backend, or form submission service in this website.
