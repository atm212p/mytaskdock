WHY MYTASKDOCK

일은 끝났는데,
어떻게 했는지 기억나나요?

업무 지시는 쪽지에, 관련 자료는 폴더에, 진행 상황은 스티커 메모에. 나중에 다시 보려면 흩어진 내용을 처음부터 찾아야 합니다.

MyTaskDock은 이 조각들을 업무 하나에 모읍니다. 무엇을 할지뿐 아니라, 무엇을 요청받았고 어떻게 처리했는지도 남도록.

01 / 업무 공간

하나의 업무,
한곳에 모인 맥락.

받은 지시와 활동 이력, 내 메모, 관련 파일을 업무 상세에서 함께 확인합니다. 메인 창의 패널로 보거나 별도 업무 창으로 열 수 있습니다.

  • 받은 지시와 활동 이력을 함께 확인
  • 자동 저장되는 업무별 내 메모
  • 별도 창과 항상 위 표시

02 / 캘린더

지금 살펴볼 업무를
한눈에.

캘린더에서 기간을 보고, 업무 선반에서 지연·오늘·예정 업무를 확인합니다. 시간 약속이 있는 일정은 업무와 구분해 기록할 수 있습니다.

  • 월간·2주 보기
  • 지연·오늘·예정 업무 그룹
  • 캘린더에서 업무 이동과 기간 조정

03 / 지시·이력

받은 요청도,
달라진 과정도.

보낸 사람과 받은 시각을 붙여 지시를 추가합니다. 날짜 변경, 파일 추가, 완료 같은 활동 기록과 함께 업무의 흐름을 다시 살펴볼 수 있습니다.

  • 본문 붙여넣기·지원되는 쪽지 파일 가져오기
  • 받은 지시와 내 작업 메모를 구분
  • 지원되는 업무 활동을 이력으로 기록
이미지 크게 보기
04 / 관련 파일

평범한 로컬 파일을
업무와 함께.

작업 파일을 일반 로컬 업무 폴더에 모읍니다. 간단한 업무는 폴더 없이 시작하고, 나중에 파일을 넣을 때 폴더를 만들 수 있습니다.

  • 끌어 놓아 복사·지원되는 Shift 드롭으로 이동
  • 연결된 기존 프로그램으로 파일 열기
  • 문서 본문 분석·파일 버전 관리는 제공하지 않음
이미지 크게 보기
05 / 기록 보관함

완료는 삭제가
아니니까.

업무를 완료하면서 처리 결과를 남기고, 나중에 기록 보관함에서 다시 찾습니다. 직접 삭제하지 않는 한 기록과 파일은 유지됩니다.

  • 제목·지시·메모·처리 결과 검색
  • 파일 이름 검색, 문서 본문 검색은 아님
  • 상태·월별 필터와 업무 다시 진행
이미지 크게 보기
06 / 빠른 등록

지금 가진 내용으로
바로 시작.

제목과 날짜를 입력하고, 필요한 지시나 파일을 함께 넣어 등록합니다. 새 업무를 만들거나 기존 업무에 내용을 추가할 수 있습니다.

  • 업무와 일정 구분
  • 발신자·받은 시각·파일 선택 입력
  • 가벼운 업무는 폴더 없이 등록

제품 이미지는 실제 컴파일된 WPF 화면에 가상 데이터를 넣어 렌더링했습니다. 현재 앱은 한국어 UI이며 영문 업무 내용은 예시 데이터입니다.

요청에서 기록까지

작은 흐름이 쌓여,
다시 쓸 수 있는 업무 기록으로.

보고서 작성, 행정 업무, 후속 조치처럼 파일과 지시가 함께 쌓이는 개인의 Windows 업무를 위한 흐름입니다.

01

업무를 담고

업무를 만들고 날짜를 정합니다. 이미 받은 지시나 파일도 함께 넣습니다.

02

맥락을 모으고

새 요청을 추가하고, 내 메모를 고치며, 작업에 필요한 파일을 모읍니다.

03

결과를 남기고

완료 처리와 함께 필요한 경우 결과를 적습니다. 완료해도 기록은 삭제되지 않습니다.

04

다시 찾아보기

보관함에서 검색하거나 날짜별로 살펴봅니다. 후속 업무가 생기면 다시 진행할 수 있습니다.

내 데스크톱에서

또 하나의 클라우드 대신,
내 로컬 폴더에.

기록은 로컬 데이터로, 파일은 일반 폴더로

현재 앱은 업무 데이터를 로컬 JSON과 일반 파일로 저장합니다. 별도의 호스팅 애플리케이션 서버는 없습니다.

가벼운 업무는 가볍게

폴더 없는 할 일로 시작해 파일이 필요할 때 폴더를 추가합니다. 업무와 별개인 스티커 메모도 사용할 수 있습니다.

향후 검토 아이디어

모인 기록을 바탕으로,
다음에는 무엇을 할 수 있을까요?

검토 제안 · v0.4.8에 미구현

현재 앱에는 Claude가 연동되어 있지 않습니다. 아래는 기존 업무 기록을 활용해 검토할 실험 후보이며, 개발 중인 기능이나 확정된 출시 일정이 아닙니다.

01 / CLAUDE 활용 후보

다음 행동 제안

사용자가 선택한 지시에서 할 일을 제안하고, 근거가 된 요청을 함께 보여주는 방향입니다. 모호한 날짜는 일정에 반영하지 않고 확인 질문으로 남깁니다.

선택한 지시 → 행동 제안 → 사용자 검토
02 / CLAUDE 활용 후보

다시 시작할 때 업무 요약

업무의 요청, 메모, 변경 사항과 미해결 질문을 필요할 때 짧게 정리하는 방향입니다. 원래 지시와 메모는 요약과 별개로 유지합니다.

선택한 업무 기록 → 근거를 연결한 요약
03 / CLAUDE 활용 후보

처리 결과 초안

사용자가 실제로 마친 일을 바탕으로 짧은 결과 문장을 작성하는 방향입니다. 초안은 수정할 수 있고, 완료 여부는 사용자가 확정합니다.

실제 완료 내용 → 수정 가능한 결과 초안
제안하는 원칙: 보낼 내용은 직접 선택.

향후 외부 API를 사용하려면 전송할 텍스트를 선택·확인하는 단계가 필요합니다. 제안이 업무를 바꾸기 전에는 사용자가 검토해야 합니다. 현재 로컬 저장 방식이라고 해서 미래의 Claude 기능까지 오프라인으로 작동하는 것은 아닙니다.

추가로 검토할 방향선택 가능한 아이디어 · 확정 로드맵 아님

한 업무를 대상으로 한 AI 실험 외에 아래 확장도 별도로 검토할 수 있습니다. 현재 구현되거나 일정이 잡힌 기능은 없습니다.

선택한 과거 업무 비교

후속 Claude 후보: 사용자가 고른 소수의 보관함 기록을 비교하고, 답변의 근거가 된 업무로 연결합니다.

백업·복원 보조

추가 제품 아이디어: 데이터 폴더를 수동 복사하는 방식에서 나아가, 로컬 스냅샷과 복원 전 미리보기를 지원합니다.

반복해서 쓰는 업무 틀

추가 제품 아이디어: 익숙한 업무의 제목·메모 양식·선택적 폴더 구성을 재사용합니다. 자동 반복 업무 기능과는 별개의 방향입니다.

현재 프로젝트

개발 초기 제품이지만,
업무 흐름은 구체적으로.

MyTaskDock은 개인의 업무 기록을 위한 초기 Windows 데스크톱 프로젝트입니다. v0.4.8에는 캘린더, 업무 상세, 로컬 파일, 받은 지시, 메모, 처리 결과와 기록 보관함 검색이 구현되어 있습니다.

Windows 데스크톱한국어 UI소스 버전 0.4.8

제품 기준: 소스 v0.4.8, 2026년 10월 7일 검토. 실제 프로그램 소스는 비공개이며, 제품 이미지에는 고객 정보가 아닌 가상 데이터를 사용했습니다.

자주 궁금한 내용
웹이나 팀 협업 서비스인가요?

아닙니다. 현재 제품은 개인용 Windows 데스크톱 앱이며 이 홈페이지는 제품 소개용입니다. 팀 공유, 클라우드 동기화, 웹·모바일 앱은 구현되어 있지 않습니다.

이미 Claude를 사용하나요?

아닙니다. 위 Claude 기능은 검토 후보입니다. 현재 호환 메신저 창의 내용을 읽는 기능은 로컬 텍스트 추출과 Windows OCR을 사용하며 생성형 AI가 아닙니다. 호환성이나 인식 결과에 따라 검토·수동 입력이 필요합니다.

어디까지 검색하나요?

업무 제목, 받은 지시와 발신자 정보, 내 메모, 처리 결과, 표시되는 파일 이름을 검색합니다. 첨부 문서 본문이나 독립 스티커 메모는 업무 검색에 포함되지 않습니다.

모든 기록이 영구 보존되나요?

완료해도 업무 기록과 파일은 유지되지만 직접 삭제할 수 있습니다. 활동 이력은 변경 불가능한 감사로그나 메모의 전체 수정본, 파일 버전 이력이 아닙니다.

여기서 앱을 받을 수 있나요?

현재 페이지는 초기 제품과 구현된 업무 흐름을 소개하며 공개 다운로드는 제공하지 않습니다. 프로젝트에 관한 질문은 아래 이메일로 보내주세요.
